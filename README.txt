DR. SHALINI R — PREMIUM 3D PORTFOLIO

This is a static GitHub Pages-ready portfolio.

Deploy:
1. Upload the contents of this folder to the root of your GitHub repository.
2. Ensure index.html is in the repository root.
3. GitHub Settings -> Pages -> Deploy from a branch -> main -> /(root).
4. Save and wait for the Pages deployment to complete.

The site retains the supplied portfolio data, including biography, education, professional journey, documentary filmography, publications, conference presentations, skills, and contact details.
